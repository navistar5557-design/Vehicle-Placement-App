# CUBE AI Gemini activation
This branch deliberately keeps Gemini disabled. Do not merge or activate until the Firebase owner has verified the project is on Spark without a linked billing account, enabled AI Logic with Gemini Developer API, registered the existing web app, and enforced production App Check for AI Logic. Obtain the public Firebase web app ID and public reCAPTCHA v3 site key for the GitHub Pages domain. Do not commit secrets or enable billing. Set the config flags only after confirming these steps, then run a non-sensitive live intent test and authenticated app regression tests. The local analytics engine is authoritative. The optional cloud model receives only user-approved generic question text and a static intent list, not trip records. Users can decline consent. The SDK upgrade must be checked against production authentication, Firestore, messaging and storage before release.
